# FIP

A small Chrome extension that plays FIP **Live**, **Groove**, **Jazz**, and **Electro** from the toolbar. Audio keeps going after the popup closes.

## Install

1. Open `chrome://extensions`
2. Turn on **Developer mode**
3. Click **Load unpacked** and select this folder

Click the FIP icon in the toolbar. Click a station to play; click it again to pause.

Streams are Radio France’s public Icecast URLs. Now-playing comes from their public livemeta API.

IBM Plex Sans is bundled under the SIL Open Font License (`fonts/OFL.txt`).
