# FIP

A small Chrome extension that plays FIP and its webradios from the toolbar. Audio keeps going after the popup closes.

Stations: Live, Groove, Jazz, Electro, Cultes, Sacré français !, Rock, Reggae, Pop, Monde, Nouveautés, Hip-Hop, and Metal. Live, Groove, Jazz, and Electro keep their original streams and colors.

## Install

1. Open `chrome://extensions`
2. Turn on **Developer mode**
3. Click **Load unpacked** and select this folder

Click the FIP icon in the toolbar. Click a station to play; click it again to pause. The sliders button opens settings, where you choose which stations appear and the color of each one. Every station is on until you turn it off.

Streams are Radio France’s public Icecast URLs. Now-playing comes from their public livemeta API.
